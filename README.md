# Virtual Piano with Hand Tracking

A virtual piano controlled by hand gestures using Python, OpenCV, MediaPipe, and Pygame.

## Features
- Real-time hand tracking
- Two-hand support
- Virtual piano with white keys
- Sound playback using Pygame
- Visual feedback for active keys

## Requirements
```bash
pip install opencv-python mediapipe pygame
```

## How to Run
1. Clone the repository.
2. Open `Virtual_Piano.ipynb` in Jupyter Notebook.
3. Run the notebook.
4. Use your index fingers to play the piano.

Press `Q` to exit.

## Technologies
Python | OpenCV | MediaPipe | Pygame | Jupyter Notebook
